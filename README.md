# Digital Queue Management System (Java JDBC)

This is a console-based Digital Queue Management System designed for clinics using Java and JDBC.

## 🚀 Features
- Add patient and generate token
- View patient queue
- Serve next patient (FIFO logic)
- View last served patient

## 🛠 Technologies Used
- Java
- JDBC
- MySQL

## 🧠 Concepts Used
- Queue (FIFO) logic
- Database ordering using SQL
- Real-time status tracking

## ▶️ How to Run
1. Create database in MySQL
2. Update DB credentials
3. Run Main.java

## 📌 Highlights
- Token-based queue system
- Real-world clinic workflow simulation
- Efficient patient handling
